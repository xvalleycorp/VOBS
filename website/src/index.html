Mã nguồn mở · Apache 2.0

Open Banking cho ngân hàng Việt Nam, không phải mở thẳng core

VOBS là bộ nền tảng mở giúp ngân hàng triển khai Open API theo Thông tư 64/2024/TT-NHNN: API Gateway chuẩn FAPI 2.0, quản lý consent, Integration Hub đồng bộ dữ liệu từ core, cùng các thư viện VietQR và ISO 20022. Fintech kết nối nhiều ngân hàng qua cùng một kiểu API.

Mọi ngân hàng đang giải cùng một bài toán

Ngân hàng phải mở API theo chuẩn chung, trong khi hệ thống lõi không được thiết kế cho việc đó. Phần việc này giống nhau giữa các ngân hàng và không tạo lợi thế cạnh tranh.

Quy định

Thông tư 64 đặt chuẩn và hạn chót

Danh mục Open API cơ bản, consent tối đa 180 ngày, giới hạn truy vấn tự động, lưu log tối thiểu 3 tháng, hệ thống đạt an toàn cấp độ 3.

Core banking

Core cũ không chịu được tải mở

T24, Flexcube, Silverlake có batch cuối ngày, giới hạn thông lượng và chi phí mở rộng theo license. Mở API đọc thẳng vào core là đặt rủi ro vận hành lên mọi đối tác.

Fintech

Mười ngân hàng là mười dự án

Mỗi ngân hàng một kiểu API, một quy trình onboarding. Chi phí tích hợp tăng theo số ngân hàng thay vì dùng lại.

Dữ liệu cá nhân

Consent phải rõ ràng và truy vết được

Nghị định 13/2023/NĐ-CP và luật về dữ liệu đòi hỏi consent có phạm vi, có thời hạn, thu hồi được, và mọi truy cập đều có bản ghi.

Tách luồng đọc khỏi luồng ghi

Request đọc lấy dữ liệu từ kho đọc mà Integration Hub đồng bộ liên tục từ core, nên tải lên core không tăng theo số đối tác. Lệnh ghi như khởi tạo thanh toán đi qua hệ thống của chính ngân hàng; VOBS không ghi vào core bằng đường tắt.

Mười module, dùng riêng được

Ngân hàng có thể chỉ lấy thư viện ISO 20022 hay chỉ lấy module consent. Phần hạ tầng lắp từ dự án open-source đã trưởng thành; phần tự xây tập trung vào những gì đặc thù Việt Nam. Trạng thái dưới đây phản ánh đúng mã nguồn hiện tại.
